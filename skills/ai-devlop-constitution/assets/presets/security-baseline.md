# 通用代码级安全规范初始化预设

> 适用范围：不限编程语言与框架，可作为任意项目首次初始化 `.ai-dev/memory/security.md` 的通用安全基线。
> 使用方式：初始化安全规范时，结合项目实际入口、数据敏感性与业务场景裁剪落地为五字段规则；不涉及的条款可保留标题并说明不适用依据。

## 一、输入校验与防注入

- **严格输入校验**：对所有外部输入（URL 参数、请求体、Header、Cookie）在服务端校验类型、长度、格式与取值范围，优先采用白名单而非黑名单。
- **防 SQL 注入**：所有数据库查询必须使用参数化查询 / 预编译语句，严禁将用户输入直接拼接进 SQL；无法参数化的动态部分（如排序字段、表名）必须经过严格的白名单映射。
- **防命令与代码注入**：严禁将外部输入直接拼接到系统命令执行函数、动态脚本引擎或表达式解析器中；若必须调用，需严格限定允许的参数集合。
- **防 XSS（跨站脚本）**：所有输出到页面的不可信数据必须进行上下文相关的编码/转义；渲染富文本前必须使用成熟的过滤库按白名单清洗危险标签与属性；动态拼接链接时校验协议，禁止 `javascript:` 等伪协议。

## 二、权限控制与防越权

- **防水平越权（数据归属校验）**：查询、修改、删除单条数据时，严禁信任客户端传入的用户 ID 或租户 ID，必须从服务端当前登录态中提取操作者身份，并在数据访问层强制校验该资源是否归属当前用户。
- **防垂直越权（功能权限校验）**：所有管理端或高权限接口必须在服务端显式校验角色与权限点，不能仅靠前端隐藏菜单或按钮。
- **防批量赋值（越权篡改字段）**：接收客户端提交的数据时，必须明确指定允许修改的字段白名单，严禁直接将整个请求体自动绑定并写入数据库模型（防止额外传入角色、余额、审核状态等敏感字段）。
- **防开放重定向**：登录跳转、回调等接收外部跳转地址的逻辑，必须校验目标地址是否为站内相对路径或白名单域名，防止跳转至钓鱼站点。

## 三、敏感数据与密码学安全

- **密码存储**：严禁明文或无盐弱哈希（如普通 MD5/SHA1）存储密码，必须使用带随机盐的慢哈希算法（如 Argon2、BCrypt、PBKDF2）。
- **加密与随机数**：对称加密须使用安全的认证加密模式（如 GCM），严禁使用不安全的模式（如 ECB）或硬编码固定初始向量（IV）；生成 Token、验证码、会话 ID、密钥时必须使用密码学安全的随机数生成器，严禁使用普通伪随机数。
- **严禁硬编码敏感信息**：源代码中严禁出现数据库密码、第三方 API 密钥、加密私钥、测试后门账号。
- **日志与响应脱敏**：严禁在日志中打印密码、会话凭证、完整证件号、银行卡号等敏感信息；接口返回对象中主动剔除内部字段与敏感字段，展示类敏感信息按需做掩码脱敏。
- **错误信息收敛**：全局异常处理中，严禁将程序堆栈、SQL 语句、内部文件路径、框架版本直接返回给客户端，仅返回通用提示与错误码。

## 四、文件与网络请求安全

- **文件上传校验**：校验文件后缀白名单（仅允许业务必需类型）；校验文件真实内容/文件头防止伪装；服务端重新生成随机文件名存储，严禁使用客户端传入的原始文件名；代码层校验文件大小上限。
- **防路径遍历**：读取或下载文件时，严禁直接将外部传入的路径/文件名与基础目录拼接；应通过唯一 ID 映射查库获取真实路径，或将路径规范化后强制校验其仍在允许的根目录内。
- **防 SSRF（服务端请求伪造）**：当服务端需要根据外部传入的 URL 发起网络请求时，必须限制协议（仅允许 HTTP/HTTPS），并解析目标域名对应的 IP，拦截回环地址、局域网内网段及云元数据地址。

## 五、业务逻辑与并发安全

- **防并发竞态（超卖/超扣）**：涉及余额、库存、积分、优惠券核销等数值扣减逻辑，严禁“先查询判断，再更新写入”，必须使用数据库原子条件更新、悲观/乐观锁或分布式锁保证并发安全。
- **接口幂等性**：下单、支付、状态流转等关键写操作，必须在代码层通过唯一业务单号、状态机校验或防重 Token 保证重复请求不会产生多次副作用。
- **反序列化安全**：严禁直接反序列化来自不可信渠道的二进制或对象流；使用 JSON/XML 等反序列化时，关闭自动多态类型推导或配置严格的类白名单。
- **资源耗尽防护（防 DoS）**：分页查询必须在代码层限制单页最大条数上限，防止一次拉取全表；避免使用存在回溯灾难风险的复杂正则表达式处理不可信长文本；解压外部上传的压缩包时校验解压后总大小与文件数量（防压缩炸弹）。

## 六、客户端代码安全

- **会话彻底清理**：用户主动退出或登录态失效时，代码必须清除所有本地存储、内存状态中的凭证与用户敏感数据。
- **外链隔离**：新窗口打开第三方外部链接时，必须在属性上隔离源页面上下文引用，防止新页面反向篡改原页面。
- **调试信息清理**：生产构建或发布前，清除或禁用包含敏感数据的控制台日志输出与调试模式开关。
